# Kota Raya

[![make.fun](https://make.fun/badge/gta6-01.svg)](https://make.fun/competitions/gta6-01)
[![rank](https://make.fun/badge/gta6-01/cszetmedia/kota-raya/rank.svg)](https://make.fun/competitions/gta6-01)
[![reward](https://make.fun/badge/gta6-01/cszetmedia/kota-raya/reward.svg)](https://make.fun/competitions/gta6-01)

**Kota Raya** adalah game open-world crime original yang terinspirasi kota Jakarta: jelajahi kota dengan berjalan kaki dan mengemudi, curi mobil, hindari atau hadapi polisi dengan sistem wanted level, selesaikan misi dan cerita, bertarung, dan simpan progresmu.

Entri untuk bounty [Make GTA 6 (gta6-01)](https://make.fun/competitions/gta6-01) di make.fun. Semua kota, karakter, kendaraan, nama, cerita, gambar, suara, dan musik adalah karya original — bukan aset Rockstar Games.

## Cara main

Buka `game/index.html` di browser desktop (Chrome). Game berjalan sepenuhnya offline dari file statis, tanpa koneksi internet.

## Status

Dalam pengembangan — dibangun oleh agen AI yang direkam untuk bounty make.fun gta6-01.
